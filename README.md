✨ Glow Beauty Studio

A modern, elegant, and responsive website designed for a beauty and wellness studio.

Glow Beauty Studio provides a clean and welcoming online presence where visitors can explore beauty services, view the studio gallery, learn about the business, and get in touch for appointments.

 Project Overview

Glow Beauty Studio is a WordPress website created with a focus on clean design, responsive layouts, and a professional user experience.

The website uses a soft and elegant visual style to match the beauty and wellness industry while keeping the navigation simple and easy to use.

 Technologies Used

- WordPress
- Elementor
- Astra Theme
- HTML
- CSS
- Responsive Web Design

 Features

- Modern and elegant homepage
- Responsive design for desktop, tablet, and mobile
- Hero section with call-to-action
- Beauty services showcase
- About section
- Why Choose Us section
- Image gallery
- Contact page
- Contact form
- Appointment call-to-action
- Clean navigation and user-friendly layout

 Website Pages

 🏠 Home
Introduces Glow Beauty Studio with a hero section, services, about section, benefits, gallery, and appointment call-to-action.

 👩 About
Provides information about the studio, its story, and its approach to beauty and wellness.

 💇 Services
Showcases the main services offered:

- Hair Styling
- Facial & Skincare
- Makeup Services
- Spa & Wellness

 🖼️ Gallery
Displays a collection of beauty and studio images to give visitors a visual feel of the experience.

 📩 Contact
Provides contact information and a contact form for visitors to get in touch with the studio.

 🎨 Design

The website follows a soft, feminine, and modern visual style with:

- Elegant typography
- Soft pink and neutral tones
- Clean spacing
- Rounded cards and buttons
- Large visual sections
- Responsive layouts

 Project Purpose

This project was created as a portfolio website to demonstrate WordPress website design and development skills for a beauty and wellness business.

The focus was on creating a professional, visually appealing, and easy-to-navigate website using WordPress and Elementor.
